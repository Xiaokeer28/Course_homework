# Sorbonne University MS2A Coursework

This repository contains coursework completed as part of the **MS2A (Mathematics, Statistics, and Learning)** program at Sorbonne University.

## Courses

- Modern Learning (*Apprentissage moderne*)
- Statistical Learning (*Apprentissage statistique*)
- Deep Learning
- Data Protection (*Protection de données*)
- Computer Vision (RDFIA)
- Extreme Value Theory (*Valeurs extrêmes*)

The repository includes practical assignments, projects, and related course materials.
